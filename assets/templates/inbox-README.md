# inbox — not yet placed

**This is the correct default, not a failure.**

Anything thrown in before it is clear which branch owns it lives here, with one line saying what it is and when it arrived.

## Why this exists

**A wrong file in a right-looking place is worse than an unsorted one** — it reads as decided. An agent that guesses at a branch in order to look tidy creates damage that only surfaces months later, when someone trusts the placement.

## Rules

- Not sure → here, with a note.
- **Emptied during the weekly review, not before.** An inbox emptied on arrival is an inbox being guessed at.
- An item sitting here for over a month is **data**: either it does not matter, or a branch is missing.

## Example line

`2026-07-26 — link to a time-tracking tool. Unclear whether it belongs to work or teaching. Awaiting a decision.`

# Decision log

> **Append-only. An existing line is never edited.** A reversed decision gets a new line that supersedes the old one, so the reversal itself stays visible.
> Where this folder has no version control, **this file is the entire memory of the system.** What is not written here happened, and nobody will ever know why.

Format: `date · branch · what was decided · why · what it replaced`

---

### << YYYY-MM-DD >> · << branch or "system" >> · << what was decided >>
**Why:** << the reasoning, in enough detail that it can be re-evaluated later without the original conversation >> **Replaced:** << what this overrides, or "nothing — first decision" >>

### << YYYY-MM-DD >> · << branch >> · << decision >> — **assumed**
**Why:** taken in the owner's absence, using the documented default. Marked `assumed` and **due for confirmation at the quarterly review.** **Replaced:** << ... >>

---

**Writing rule:** when the owner is unavailable, take the documented default, proceed, and record it here as `assumed`. **Never stall silently** — a documented assumption can be corrected in a minute; a stalled system costs a week. Every `assumed` line is confirmed or reversed at the quarterly review.

## Rules

- **Every new file gets its row here in the same action that creates it.** A file that is not in the index does not exist — that is precisely how good material disappears.
- **Topics are renamed freely.** They are labels on a list, not folders; changing one costs nothing and breaks nothing. If a heading stops matching how the owner talks, it is wrong.
- **A topic with one file is fine.** This is a list, and lists tolerate short entries. Folders do not, which is one more reason to keep the folder flat.
- **When a topic grows past roughly ten rows** and the owner is scrolling to find things, *then* consider a sub-folder for it — named exactly like the topic here.

## Rules

- **Every new file gets its row here in the same action that creates it.** A file that is not in the index does not exist — that is precisely how good material disappears.
- **Topics are renamed freely.** They are labels on a list, not folders; changing one costs nothing and breaks nothing. If a heading stops matching how the owner talks, it is wrong.
- **A topic with one file is fine.** This is a list, and lists tolerate short entries. Folders do not, which is one more reason to keep the folder flat.
- **A new area of activity starts here as a heading, on the day it is declared** — with one row under it, or none. That is what makes the order visible immediately without a folder standing empty to prove it.
- **When a topic passes roughly five rows**, propose a sub-folder for it — named **exactly** like the heading, with no number in front. **The count is the rows here**, never a scan of the folder: no session reads a whole branch, so this list is the only place the number can honestly come from.
- **Dropped a topic before it grew?** Delete the heading. That is the whole cleanup — which is the point of it being a heading and not a folder.

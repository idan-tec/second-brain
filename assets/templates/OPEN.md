# Open — only the owner can settle these

> **One list. Not two, not four.** If something is not here, it is not actually open.
> **Every item carries a written recommendation and a default.** An open question with no recommendation is handing responsibility back, not asking for a decision — and it is the reason lists like this stop being read.

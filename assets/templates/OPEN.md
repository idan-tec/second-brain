# Open — only the owner can settle these

> **What is open lives in as few lists as this folder can get away with, and every list is registered in the map below.** While there is one working life in here, that means this file and nothing else.
> **The day something is open inside one branch and nowhere else — which arrives with a second business or a second owner — that branch gets its own `OPEN.md` with namespaced ids, and a row here.** From then on this file holds what is open at the level of the whole folder: ownership, money, the system itself, anything crossing branches. **What decides the tier is what an item touches, never how big it is.**
> **The map is the roll-up** — the only surface answering *"what is open across everything"*. **A list missing from it is open and invisible**, and an item in no list is not actually open.
> **Every item carries a written recommendation and a default.** An open question with no recommendation is handing responsibility back, not asking for a decision — and it is the reason lists like this stop being read.

## The map — every open list in this folder

| Where | ids | what it covers |
|---|---|---|
| **this file** | `O*` | brain level: ownership, money, cross-branch, the system itself |
| << branches/<< name >>/OPEN.md >> | << `ABC-O*` >> | << what that branch's list covers >> |

<< The second row appears the day a branch opens its own list, and not before — a branch list is born with its first item,

**When something is settled:** delete it from here and write it in [DECISIONS.md](DECISIONS.md) with the date and the reason. **An item never lives in two places at once** — not in both tiers, and not in both an open list and the decision log. Two lists holding the same question is how a decision gets made twice and answered differently.

**`DECISIONS.md` stays single while the open lists split.** They are not the same kind of file: an open list is a working surface and is read by whoever is working on that one branch, while the log is the history of the whole folder and is read end to end. History split four ways stops being readable as history.
